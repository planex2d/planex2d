Eigen 3.4.0

  • Project: Eigen, a C++ template library for linear algebra, https://gitlab.com/libeigen/eigen

  • Version: 3.4.0 (git tag 3.4.0, commit 3147391d; identical to the release tarball with SHA-256 8586084f71f9bde545ee7fa6d00288b264a2b7ac3607b974e54d13e7162c1c72), unmodified.

  • Source: the folder external_dependencies/eigen of planex2d’s source and of its source distribution (sdist); the Source Code Form of every Eigen file planex2d compiles is available there and at the URL above.

  • Used: the header-only modules Eigen/Core, Eigen/SparseCore, Eigen/SparseCholesky, Eigen/OrderingMethods, Eigen/SparseQR and the dense Eigen/QR and Eigen/SVD (with Eigen/Cholesky, Eigen/Householder and Eigen/Jacobi, which they include), compiled with EIGEN_MPL2_ONLY defined, so that no LGPL-licensed Eigen code can be included. Nothing from Eigen’s unsupported/ directory is used, and its BLAS, LAPACKE and MKL bindings are not enabled (EIGEN_USE_BLAS, EIGEN_USE_LAPACKE and EIGEN_USE_MKL are not defined).

Libraries planex2d uses but does not include
